YouSkill は、iPhone で Agent Skills を探して読むためのアプリです。

探して保存
カテゴリや人気のリポジトリを閲覧できます。カテゴリやリポジトリ内で検索し、人気順やスター数で並べ替え、よく使うスキルをお気に入りに保存できます。

スキルのファイルを読む
Markdown 文書を読み、ファイル一覧から関連ファイルを開けます。画像の表示と、構文を色分けしたコードの閲覧にも対応しています。

自分のモデルで翻訳
Markdown を日本語、英語、簡体字中国語、韓国語に翻訳できます。設定で対応するモデルサービスと自分の API キーを指定してください。翻訳にはモデルサービスが必要です。サービス提供元の料金が発生する場合があります。

画面に合わせた表示
iPhone Duo を横向きに開くと、カタログとスキルを並べて表示できます。折りたたみや回転後も、閲覧中の内容を引き続き読めます。幅の狭い画面では、1 列の画面を順に移動します。

インターフェイスは日本語、英語、簡体字中国語、韓国語に対応しています。
