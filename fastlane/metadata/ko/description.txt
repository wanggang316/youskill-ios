탐색과 저장
카테고리와 인기 저장소를 둘러보세요. 카테고리나 저장소 안에서 검색하고, 인기순 또는 스타 수로 정렬하며, 자주 쓰는 스킬을 즐겨찾기에 저장할 수 있습니다.

스킬 파일 읽기
Markdown 문서를 읽고 파일 목록에서 관련 파일을 열 수 있습니다. 이미지 보기와 구문 강조를 적용한 코드 읽기도 지원합니다.

자신의 모델로 번역
Markdown을 한국어, 영어, 중국어 간체, 일본어로 번역하세요. 설정에서 호환되는 모델 서비스와 자신의 API 키를 입력할 수 있습니다. 번역에는 모델 서비스가 필요하며 서비스 제공업체의 요금이 발생할 수 있습니다.

화면에 맞춘 표시
iPhone Duo를 가로로 펼치면 카탈로그와 스킬을 나란히 볼 수 있습니다. 기기를 접거나 회전한 뒤에도 보고 있던 내용을 계속 읽을 수 있습니다. 좁은 화면에서는 한 열씩 이동합니다.
