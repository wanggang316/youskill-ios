YouSkill 帮助你在 iPhone 上发现和阅读 Agent Skills。

浏览与收藏
按分类或热门仓库浏览技能，在当前分类或仓库内搜索，按热度或 Star 数排序，并收藏常用技能。

阅读技能文件
阅读 Markdown 文档，通过文件目录查看关联文件，浏览图片，并以语法高亮方式查看代码。

使用自己的模型翻译
将 Markdown 翻译为简体中文、英语、日语或韩语。在设置中配置兼容的模型服务及自己的 API 密钥。翻译需要模型服务，服务提供方可能收取费用。

适配不同屏幕
在 iPhone Duo 上横向展开设备，可并排浏览目录和技能。折叠或旋转设备时继续阅读当前内容，窄屏下采用单栏逐级导航。

界面支持简体中文、英语、日语和韩语。
